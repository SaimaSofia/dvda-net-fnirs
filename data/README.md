# Data

Put the UFFT subject CSV files in `ufft/`.

Dataset paper:
Bak et al., "Open-access fNIRS dataset for classification of unilateral finger- and foot-tapping," Electronics, 2019.

Figshare:
https://doi.org/10.6084/m9.figshare.9783755.v1

Expected files look like:
```
data/ufft/fNIRS 01.csv
data/ufft/fNIRS 02.csv
...
data/ufft/fNIRS 30.csv
```

Each CSV should have channel feature columns and a `class` column.
